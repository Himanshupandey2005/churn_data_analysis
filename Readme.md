# 📊 Customer Churn Analysis

## 📌 Project Overview

This project focuses on analyzing customer churn to understand **why customers leave a business** and identify the key factors associated with customer attrition.

The analysis explores customer demographics, subscription plans, contract types, escalations, churn scores, and other relevant attributes to uncover patterns and trends that can help businesses improve **customer retention and reduce churn**.

---

## 🎯 Objectives

* Analyze overall customer churn patterns.
* Identify factors contributing to customer churn.
* Compare churn rates across different customer segments.
* Analyze churn based on plan and contract types.
* Identify high-risk customer segments.
* Explore the relationship between escalations and churn.
* Generate meaningful insights that can support customer retention strategies.

## 🔍 Analysis Performed

### 1. Data Cleaning

* Handled missing values.
* Checked and removed duplicate records.
* Corrected data types.
* Prepared categorical and numerical columns for analysis.

### 2. Exploratory Data Analysis (EDA)

Performed analysis to understand:

* Overall churn distribution.
* Churn rate by state.
* Churn across different plan types.
* Churn based on contract type.
* Relationship between escalations and churn.
* Distribution of churn scores.
* Customer churn risk categories.

### 3. Customer Segmentation

Customers were analyzed based on different attributes such as:

* **Plan Type**
* **Contract Type**
* **Churn Risk**
* **Churn Score**
* **Escalations**
* **Geographical Location**
